Core System Architecture & Basic Mechanism

How the Test-Setup Optimizer Works

When a user uploads a STIL file, the agent isolates the TEST_SETUP initialization sequence from the scan pattern payload. It expands tester clock loops, parses 6 JTAG/IJTAG pin states, and uses a combination of deterministic IEEE rules and a Learning-to-Defer (LtD) gradient-boosted model to classify every individual clock cycle as Keep Clock, Redundant (Cut), or Defer to Human. The scan payload is passed through completely untouched, guaranteeing 100% zero-distortion and zero fault-coverage loss.

● Mechanism Block Diagram
4-Stage Pipeline with Untouched Payload Highway
Stage 1

Ingestion & Isolation

  • User uploads STIL file: Supports ATPG stuck-at, scan-shift, and MBIST suites.
  • Boundary Isolator: Distinguishes initialization instructions (TEST_SETUP) from heavy pattern shift data.
  • Zero Payload Distortion: The scan pattern vectors are locked and bypassed completely.
Stage 2

Dissection & Expansion

  • Loop Expander: Converts STIL compressed loops (Loop 5 { V }) into 5 explicit clock vectors.
  • 6-Pin Matrix: Extracts exact binary stimulus for JTAG/IJTAG pins: TCK, TMS, TDI, TDO, TRST, RST.
  • Commonality Check: Identifies headline matches and step consistency across multiple pattern runs.
Stage 3

Rules & Learning-to-Defer

  • IEEE Deterministic Rules: Checks JTAG 1149.1 & 1687 standards (duplicate TAP resets, redundant TRST holds, idle holds).
  • 13-D Feature Vector: Compiles pin transitions, TAP state history, and rule hints into a cycle tensor.
  • LtD Gradient Booster: Recommends Cut (P > 0.65), Keep (P < 0.35), or Defers ambiguous cycles (0.35–0.65) to the engineer.
Stage 4

Rewrite & Emission

  • Human Review Store: Engineers confirm or override deferred recommendations; logged with 6x retrain weight.
  • AST Preserving Rewriter: Reconstructs STIL test setup without breaking timing annotations or syntax.
  • Output: Produces clean *_opt.stil bundle with eliminated clock waste.
● Decision Engine: IEEE Invariants vs. Machine Learning
Safety Guaranteed

1. Deterministic IEEE 1149.1 / 1687 Rule Engine

Before any machine learning prediction is accepted, the rule engine checks safety-critical JTAG & IJTAG invariants. Hard mathematical rules prevent any clock from being cut if it impacts circuit initialization:

Cut: Redundant 2nd TAP Reset (5x TMS=1) Cut: Duplicate TRST / Pin Reset Holds Cut: Post-Reset / Post-IJTAG Idle Holds IMMUTABLE: IR Scan Transitions (Shift-IR) IMMUTABLE: SIB (Segment Insertion Bit) Gates IMMUTABLE: TDR Data Capture & Exit-DR

2. Learning-to-Defer (LtD) Gradient Booster

Instead of making reckless binary decisions on borderline clocks, the model explicitly computes prediction confidence. If uncertainty exists, it defers to the test engineer:

  • P_cut > 0.65 → Recommend Redundant / Cut: High confidence clock waste (safe to remove).
  • 0.35 ≤ P_cut ≤ 0.65 → DEFER (Human Review): Flagged in UI for one-click engineer approval.
  • P_cut < 0.35 → Recommend Keep Clock: Essential setup clock (protected).
  • Retrain Loop: Engineer choices are given 6x sample weight in next retraining iteration.

Summary: Clean, Safe, and Automated Clock Optimization

The user simply provides the .stil file. The system separates the TEST_SETUP block, tests every single clock cycle against deterministic IEEE rules and the Learning-to-Defer model, flags wasteful clocks as Redundant, protects critical cycles as Keep, defers edge cases to human approval, and reconstructs the final STIL file with an untouched scan payload.
