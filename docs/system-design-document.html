Executive Summary & Problem Statement

Manufacturing Bottleneck

In modern semiconductor high-volume manufacturing (HVM), Automated Test Pattern Generation (ATPG) EDA tools (such as Synopsys TetraMAX and Siemens Tessent) generate multi-channel scan test pattern suites in Standard Test Interface Language (STIL). As SOC gate counts exceed tens of billions, scan pattern suites grow into millions of cycles across dozens of scan chains.

The Vector Memory Reload Wall (Physical Tester Constraint)

Automated Test Equipment (ATE) pin cards have strict, fixed onboard physical Vector RAM (typically 32MB to 128MB resident depth per channel). When an ATPG scan suite exceeds this resident capacity, the tester cannot execute the patterns continuously. Instead, the tester must pause playback, halt device clocking, flush vector RAM, and reload subsequent pattern bursts over slow instrumentation buses (GPIB, PCIe, or Ethernet). These multi-load reload pauses take 2 to 10+ seconds per die, stalling expensive multimillion-dollar test cells and driving wafer touch costs through the roof.

Pre-Process: LSTM Neural Compression & Diversity Engine

Machine Learning Core

● PyTorch PatternLSTMCompressor

Traditional bit-by-bit comparison of millions of scan cycles across thousands of patterns is computationally intractable. The Verilumen engine implements a dedicated 2-layer Recurrent LSTM sequence model (in lstm_compressor.py) to compress the multi-channel scan bitstream into a dense geometric vector space.

  • Input Dimension: Reads active tester channels n_channels (e.g. 23 pins) per clock cycle.
  • Recurrent Depth: 2 stacked LSTM layers with hidden dimension of 64 units.
  • Bottleneck Projection: Linear output projection layer mapping 64 units down to a compact 32-dimensional embedding.
  • L2 Hypersphere Projection: Euclidean normalization projects all patterns onto a 32-D unit sphere (||e||_2 = 1.0), turning complex bit sequence differences into simple Euclidean distance.
Formal LSTM Recurrent Equations
f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f) \quad \text{(Forget Gate)}
i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i) \quad \text{(Input Gate)}
C_t = f_t \odot C_{t-1} + i_t \odot \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)
o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) \quad \text{(Output Gate)}
h_t = o_t \odot \tanh(C_t) \quad \text{(Hidden State)}
\hat{e} = \frac{W_{out} \cdot h_{T}[-1] + b_{out}}{\| W_{out} \cdot h_{T}[-1] + b_{out} \|_2} \quad \text{(L2 Embedding)}
Captures both spatial pin correlations and long-range temporal sequential stimulus across the scan chain.

● Greedy Farthest-Point Diversity Ranking

Once all patterns are embedded in 32-dimensional hyperspace, the selector (pattern_selector.py) autonomously determines WHICH patterns to keep and HOW MANY.

Greedy Selection & Marginal Diversity Gain
S_0 = \{ P_0 \} \quad \text{(Seed with first ATPG initialization pattern)}
P_{k+1} = \arg\max_{i \notin S_k} \left( \min_{j \in S_k} \| \hat{e}_i - \hat{e}_j \|_2 \right)
\Delta g_{k+1} = \min_{j \in S_k} \| \hat{e}_{P_{k+1}} - \hat{e}_j \|_2 \quad \text{(Marginal Gain)}
Iteratively chooses the pattern that has maximum distance from all previously selected patterns, guaranteeing maximum structural test diversity across internal flip-flops.
Auto-Stopping Criteria (Saturation Curve)

As more patterns are picked, incremental diversity gain Δg naturally decays. When Δg falls below the saturation threshold (stop_ratio) or meets the vector RAM budget, the agent halts selection. The retained subset is classified as High Recommended Patterns; the remaining patterns are designated Low Risk Patterns and safely pruned from tester memory.

Physical ATE Hardware & Vector RAM Timing Model

Tester Physics & Timing

The Verilumen hardware model (ate_vector_model.py) calculates real physical tester memory consumption and pin playback time for standard production test cells (such as Advantest V93000 and Teradyne UltraFLEX).

● Physical Vector RAM Storage Equation

When scan patterns are compiled into tester binary vector memory, each pin consumes 2 bits per cycle: one bit for drive state (0/1) and one bit for expect/mask strobe (L/H/X). The sequencer and timing sets introduce a 15% formatting overhead:

Vector Memory Bytes Per Cycle
\text{BytesPerCycle} = \left( \frac{N_{\text{pins}} \times \text{BitsPerPin}}{8.0} \right) \times \text{Overhead}
\text{PeakVectorRAM (MB)} = \frac{\sum_{p \in \text{Selected}} N_{\text{cycles}}(p) \times \text{BytesPerCycle}}{1024^2}
Where BitsPerPin = 2.0, Overhead = 1.15. For 23 pins: 6.61 bytes per scan cycle.

● Tester Wall-Clock Playback Timing

Tester execution time depends on clock period period_ns (e.g. 100 ns = 10 MHz scan clock) and total clock cycles:

Playback Duration & Reload Penalty
T_{\text{playback}} (\text{ms}) = \frac{N_{\text{total\_cycles}} \times \text{Period}_{\text{ns}}}{10^6}
T_{\text{baseline}} = T_{\text{playback\_full}} + N_{\text{reloads}} \times T_{\text{bus\_reload}}
T_{\text{verilumen}} = T_{\text{playback\_subset}} + 0.0 \text{ ms} \quad \text{(Fits Resident!)}
Eliminating tester bus reload pauses completely turns a multi-second test stall into millisecond continuous playback.

Post-Process: Silicon Defect Verification & Adaptive Closed-Loop

Defect Verification & Next-Chip Optimization

● Deterministic ATE Log Ingestion & Zero Escapes

In the post-process phase, the agent ingests real hardware tester logs directly in the client browser. No large log files are transferred over the network, ensuring complete intellectual property security and instant parsing.

  • Advantest V93000 Format: Parses headers like P12 | CH3 EXPECTED... ACTUAL... STATUS:F.
  • Index Mapping: Converts 1-based log labels (P1 .. P1000) to 0-based STIL IDs (P0 .. P999).
  • Defect Cross-Reference: Categorizes actual hardware fails into Kept Pattern Fails vs Discarded Pattern Fails.
  • Coverage Guarantee: Proves empirically that defect-detecting patterns are fully preserved in the High Recommended set with zero quality escapes.

● Die N → Die N+1 Adaptive Failure-Priority Ordering

When testing consecutive dies across a wafer touch, defect signatures frequently cluster across nearby chips due to physical wafer defect gradients. The Verilumen post-processor dynamically computes failure probability rankings (nextChipRecommend.js):

Stop-on-First-Fail Fast Abort Optimization

By reordering the test suite so that patterns with high empirical defect frequency are executed first, defective dies trigger a failure in the initial milliseconds of playback. The tester can immediately abort testing and bin the bad die, saving up to 90% of test cell time on failing chips!
